# YouTube Interface Clone 🎬

A responsive YouTube-inspired interface built using HTML, CSS, and JavaScript. This project recreates the YouTube homepage experience with video thumbnails, search functionality, category filters, and a sidebar.

## ✨ Features

- Responsive interface for desktop and mobile devices
- YouTube-inspired dark theme
- Search bar with video filtering
- Video thumbnails loaded from the internet
- Video titles, channel names, views, and upload dates
- Category filters for Music, Gaming, Coding, Design, News, and more
- Interactive sidebar navigation
- Video preview modal
- Browser voice search where supported
- Indian currency symbol (₹) in the gaming setup example
- Fallback thumbnail loading

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

No additional libraries or frameworks are required.

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Ensure you have an internet connection to load the thumbnails.

You can also open the project in Visual Studio Code and use the Live Server extension.

## ⚠️ Limitations

This project is a front-end demonstration and is not affiliated with YouTube.

- The video preview is a placeholder and does not play actual videos.
- User authentication and video uploads are not implemented.
- Likes, comments, and subscriptions are not connected to a backend.
- External thumbnails require an internet connection.
